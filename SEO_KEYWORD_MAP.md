# QRPrintly SEO Keyword Map

## SEO Goal

QRPrintly should grow through long-tail SEO traffic first.

The goal is not to rank immediately for only:

- QR code generator

That keyword is highly competitive.

The first goal is to rank for specific QR generator use cases.

## Primary SEO Pages

| Page | Primary Keyword | Secondary Keywords | Search Intent |
|---|---|---|---|
| `/` | free QR code generator | QR code generator online, QR code maker | User wants a general QR generator |
| `/upi` | UPI QR code generator | free UPI QR code generator, UPI QR code for shop | User wants a QR for UPI payment |
| `/whatsapp` | WhatsApp QR code generator | WhatsApp QR code for business, WhatsApp chat QR code | User wants people to open WhatsApp chat by scanning |
| `/wifi` | WiFi QR code generator | WiFi QR code for guests, WiFi password QR code | User wants to share WiFi access easily |
| `/vcard` | vCard QR code generator | business card QR code generator, contact QR code | User wants to share contact details |
| `/templates` | QR code templates | printable QR code templates, QR poster templates | User wants a designed QR layout |
| `/website` | website QR code generator | URL QR code generator, link QR code generator | User wants a QR for a website link |
| `/email` | email QR code generator | mailto QR code generator | User wants a QR that opens an email draft |
| `/sms` | SMS QR code generator | text message QR code generator | User wants a QR that opens SMS |
| `/phone` | phone QR code generator | call QR code generator | User wants a QR that starts a call |
| `/maps` | Google Maps QR code generator | location QR code generator, map QR code | User wants a QR for a location |
| `/text` | text QR code generator | plain text QR code | User wants to store plain text in a QR |

## Priority Pages for Improvement

Improve in this order:

1. Homepage
2. UPI QR page
3. WhatsApp QR page
4. WiFi QR page
5. vCard QR page
6. Templates page

## Homepage Role

The homepage should act as:

- Trust page
- Product overview
- Internal link hub
- Entry point for all QR tools

Target keywords:

- Free QR Code Generator
- QR Code Generator Online
- QR Code Maker

Homepage should not try to explain every use case deeply. It should guide users to the correct generator page.

## SEO Content Rules

Every important SEO page should have:

- One clear H1
- Short useful introduction
- Generator above the fold
- Use cases
- How-to section
- FAQ section
- Related QR tools
- Privacy note
- Download/export note

## Internal Linking Rules

Each QR page should link to:

- Templates
- Related QR types
- Homepage or QR types page

Examples:

- UPI page links to Templates and WhatsApp QR
- WhatsApp page links to Website QR and vCard QR
- WiFi page links to Templates
- vCard page links to Templates and Website QR

## Current SEO Decision

Focus on useful long-tail pages before monetization.

Do not create thin pages only for keywords. Each page must provide real utility and match the user's search intent.
